## 🤝 Coordination & Communication Rules

1. **Schema Migrations First:** No frontend or backend task dependent on schema extensions may begin before **Sprint 0 (TS-004)** is verified and applied.
2. **Branch Isolation:** Each task or feature module must be developed on its dedicated branch (`feature/F{N}-{name}`).
3. **Daily Integration Check:** Lead Agent will review active branches to ensure no overlapping edits on `schema.prisma` or shared components.
4. **Validation Checklist:** Before marked complete, every task must pass:
   - TypeScript compilation (`npm run build` or `npx tsc`)
   - RTL visual check
   - Multi-tenant `officeId` scoping check
