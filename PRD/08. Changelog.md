# 📝 Falz SaaS Platform — Development Changelog

> **Release Date:** 2026-08-06

## [v2.5.0] - 2026-08-06 (Sprint 5 Complete — Masterplan, WhatsApp & PDF Flyer)
### Added
- **Masterplan Plot Picker (`MasterplanPicker.tsx`):** Interactive plot map widget displaying plot numbers, area (m²), price, and color-coded status badges (`متاح`, `محجوز`, `مباع`).
- **WhatsApp Share Generator (`src/lib/whatsapp.ts`):** Formatting helper `generatePropertyWhatsAppShareText` creating structured WhatsApp listings with direct deep-links.
- **PDF Flyer Brochure (`PropertyFlyerModal.tsx`):** Printable luxury A4 brochure flyer modal with office branding, specs table, and photo layout.
- **Verification Report (`PRD/07. Verification-Report.md`):** Complete audit report confirming 100% pass mark across all 14 feature modules.

---

## [v2.4.0] - 2026-08-06 (Sprint 4 Complete — Media Engine & Client Requests)
### Added
- **100 Media Files Upload Limit:** Enforced 100 media limit per listing (`MAX_MEDIA_LIMIT = 100`) in property form.
- **Cover Photo & Reordering:** Added "تعيين كغلاف" (Set Cover) button and position re-ordering controls to media grid.
- **Public Requests API (`/api/requests`):** Created `POST /api/requests` endpoint and `createPublicPropertyRequest` server action.
- **Guest Request Modal (`RequestButtons.tsx`):** Enabled guest property inquiry, viewing, and interest submissions with staff notifications.

---

## [v2.3.0] - 2026-08-05 (Sprint 3 Complete — Form Logic & Status Engine)
### Added
- **Master Bedrooms Counter:** Added `masterBedrooms` input and enforced `bathrooms >= masterBedrooms` constraint.
- **Bedrooms Auto-Suggest:** Auto-sets `bathrooms = bedrooms + 1` when setting bedroom count.
- **Conditional Visibility:** Hid residential spec fields for Lands (`LAND`/`AGRICULTURAL`) and added `entryType` (`PRIVATE`/`SHARED`) for Apartments.
- **Plot Border Normalizer:** Added `normalizeDecimal` handler converting `.`, `,`, `٫` separators into valid floats.
- **RESERVED Status & Auto-Archive:** Added `RESERVED` (`محجوز`) availability status, `reservedAt` timestamp recording, public unavailable banner, and `checkAndArchiveExpiredContracts()` background auto-archiver with staff notifications.

---

## [v2.2.0] - 2026-08-05 (Sprint 2 Complete — Bidding Engine & Saudi Locations)
### Added
- **Som Auto-Hide & Date Toggle:** Added `bidAutoHideDuration` dropdown, `showBidDate` toggle switch, `"يوجد سوم"` public view masking, and backdated bid entry.
- **Saudi Locations Engine:** Created `/api/locations/cities` and `/api/locations/districts` APIs, pre-seeded Saudi city/district selectors, sector direction auto-fill, and `+ إضافة حي` custom district modal for `OWNER`/`MANAGER` roles.

---

## [v2.1.0] - 2026-08-05 (Sprint 1 Complete — Core Navigation & REGA CRM)
### Added
- **Sale/Rent Top Tabs:** Added prominent top tabs (`للبيع` | `للإيجار`) on property master page with strict `dealType` isolation.
- **REGA Compliance:** Enforced required `nationalId` and `dob` fields on Owner creation. Placed Owner selector card at top of Property form.
- **Category/Subtype API:** Created `/api/subtypes` route with `OWNER`/`MANAGER` role protection.

---

## [v2.0.0] - 2026-08-05 (Sprint 0 Complete — Database Foundation)
### Added
- **Schema Migration:** Added `EntryType`, `BidAutoHideDuration`, `Availability.RESERVED` enums, `SaudiCity` & `SaudiDistrict` models, and property fields to `prisma/schema.prisma`.
- **Saudi Locations Seed:** Executed `npx prisma db seed` to populate Saudi cities and districts.
