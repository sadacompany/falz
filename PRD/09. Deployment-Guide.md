# 🚀 Falz SaaS Platform — Deployment Guide (Coolify)

> **Document Version:** v1.0  
> **Date:** 2026-08-07  
> **Target:** Self-hosted via Coolify with Docker Compose  
> **Infrastructure:** Docker · PostgreSQL 16 · Next.js Standalone · S3-compatible storage

---

## Prerequisites

- **Coolify** installed on your VPS/server (Ubuntu 22.04+ recommended)
- **Docker** and **Docker Compose** v2+
- **Domain name** pointed to the server's IP (e.g. `falz.sa` or `app.falz.sa`)
- **SSL** managed automatically by Coolify (via Traefik + Let's Encrypt)

---

## Quick Start (3 Steps)

### Step 1: Clone the Repository

```bash
git clone https://github.com/sadacompany/falz.git
cd falz
```

### Step 2: Configure Environment Variables

Copy the production environment template and fill in real values:

```bash
cp .env.production.example .env
```

**Required variables to set:**

| Variable | Description | Example |
|----------|-------------|---------|
| `POSTGRES_PASSWORD` | Strong database password | `S3cur3P@ssw0rd!` |
| `NEXTAUTH_SECRET` | Random 32+ character secret | `openssl rand -base64 32` |
| `NEXTAUTH_URL` | Your production domain | `https://app.falz.sa` |
| `APP_URL` | Same as NEXTAUTH_URL | `https://app.falz.sa` |

**Optional (recommended for production):**

| Variable | Description |
|----------|-------------|
| `STORAGE_PROVIDER=s3` | Switch from local to S3/MinIO for media |
| `S3_BUCKET`, `S3_REGION`, `S3_ACCESS_KEY`, `S3_SECRET_KEY` | S3 credentials |
| `EMAIL_PROVIDER=smtp` | Enable real email delivery |
| `SMTP_HOST`, `SMTP_USER`, `SMTP_PASS` | SMTP server credentials |

### Step 3: Deploy

```bash
docker compose up -d --build
```

After the containers are running, apply the database schema and seed data:

```bash
docker compose exec app npx prisma db push
docker compose exec app npx prisma db seed
```

Your app is now live at `http://your-server-ip:3000` (or behind Coolify's reverse proxy).

## Coolify-Specific Setup

If deploying via Coolify's dashboard:

1. **Create a new service** → Choose "Docker Compose"
2. **Connect your GitHub repo:** `sadacompany/falz`
3. **Set the branch:** `master`
4. **Add environment variables** in Coolify's "Environment Variables" tab (copy from `.env.production.example`)
5. **Set the domain** in Coolify's "Domains" section (e.g. `app.falz.sa`)
6. **Deploy** — Coolify will build the Docker image, start PostgreSQL, and expose the app behind Traefik with auto-SSL

## Database Management

### Run migrations after code updates:
```bash
docker compose exec app npx prisma db push
```

### Access the database directly:
```bash
docker compose exec db psql -U falz -d falz_prod
```

### Create a database backup:
```bash
docker compose exec db pg_dump -U falz falz_prod > backup_$(date +%Y%m%d).sql
```

### Restore from backup:
```bash
cat backup_20260807.sql | docker compose exec -T db psql -U falz falz_prod
```
